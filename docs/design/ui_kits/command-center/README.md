# Command Center UI kit

Interactive recreation of the core screens: Login (any 6 digits), Today, Action Items (saved views), Projects (list plus detail with related panel), Invoicing (aging band). Press N for quick add.

Also built: Meetings (list, AI summary, extracted action items with one-click create, related panel), SOPs (categorized list, rendered version, version history), Clients (registry with related projects, invoices, meetings), Templates (tagged cards with Use action), Reports (four reports with export and share actions). Only Settings remains an intentional placeholder.

Screens: `TodayScreen`, `ActionItemsScreen`, `ProjectsScreen`, `ProjectDetailScreen`, `InvoicingScreen`, `MeetingsScreen`, `SopsScreen`, `ClientsScreen`, `TemplatesScreen`, `ReportsScreen`, `LoginScreen`. All compose the system components from `components/` via the compiled bundle.
